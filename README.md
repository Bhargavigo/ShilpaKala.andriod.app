# Shilpa Kala Android App

## Problem Statement
Many small artists struggle to showcase and promote their products digitally.

## Solution
Shilpa Kala helps artists create digital portfolios and share product images easily.

## Features
- Upload product images
- Product gallery
- Branding support
- Share through social media

## Technologies Used
- Android Studio
- Kotlin
- Firebase
- XML

## Future Improvements
- Online orders
- Artist profiles
- Payment integration
